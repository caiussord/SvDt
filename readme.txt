Plugin autoral demonstrativo para reservas de serviços em uma agenda.

== Installation ==

1. Copie a pasta do plugin para wp-content/plugins.
2. Ative SvDt no painel WordPress.
3. Cadastre serviços e expediente no menu SvDt.
4. Coloque [svdt_booking] em uma página.

== Privacy ==

Nome, e-mail, telefone e observações são guardados para administrar reservas. Agendamentos cancelados ou concluídos são apagados após 12 meses. A desinstalação preserva dados por padrão; veja README.md para exclusão explícita.
